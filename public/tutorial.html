Como o sistema funciona

💡
O Vavilov OS é um copiloto de estudos, não um automatizador. Você informa o que estudou — o sistema calcula quando revisar. A disciplina de marcar corretamente é o que faz a curva de esquecimento trabalhar a seu favor.

O sistema tem três abas. Cada uma tem um papel específico no seu fluxo de estudo:

≡
Grid Excel — Central de Entrada
Onde você cadastra disciplinas, tópicos e subtópicos. Marca o que estudou, faz revisões e configura os pesos. É a fonte de verdade do sistema.
📅
Calendário (Timeblock) — Agenda Visual
Mostra o que está agendado para cada dia. Você arrasta tópicos do backlog para os horários. Os eventos ficam verdes quando concluídos.
📊
Painel Analítico — Inteligência Iudex XII
Mostra o heatmap de produtividade, o rastro de sessões e a tabela do motor Iudex com as revisões calculadas por algoritmo SM-2.
01

Montando o Edital

📄
Opção A — Ingerir PDF do edital
Clique em + Ingerir Edital (IA) e selecione o PDF do seu concurso. O Motor A tenta detectar disciplinas em CAIXA ALTA. Se não encontrar nada, o Motor B Adaptativo entra em ação buscando palavras-chave como "direito", "constitucional", "informática" etc. O resultado aparece em Caixa de Entrada.
✏️
Opção B — Adicionar manualmente
Use o painel de adição no topo: preencha Disciplina, Tópico e Peso, depois clique em Salvar no Planner. Disciplinas com o mesmo nome são agrupadas automaticamente na mesma seção do Grid.
🌿
Criando subtópicos filhos
Clique no botão + azul ao lado do 🗑️ em qualquer linha. Um modal aparece para você nomear o subtópico filho. Exemplo: Direito Administrativo → Administração Indireta → Autarquias. Não há limite de profundidade.
⚖️
Configure os pesos com cuidado
O Peso (1–5) é o dado mais importante do sistema. Ele alimenta diretamente o algoritmo Iudex. Deixar tudo em peso 1 faz o algoritmo interpretar que você nunca aprendeu bem nada, gerando revisões diárias eternas. Ver tabela de pesos →
02

Estudando e marcando

✅
Quando você termina de estudar um tópico, marque o checkbox da coluna "Estudo". Isso faz três coisas de uma vez: registra no banco, agenda o tópico no Timeblock de hoje com o horário atual, e alimenta o heatmap e o rastro no painel analítico.
☑️
Marque no Grid, não no Calendário
O checkbox do Grid é a forma principal. Ele registra a sessão corretamente. Você também pode clicar num evento no Calendário para marcá-lo, mas o fluxo primário é o Grid.
📍
O agendamento automático de hoje
Ao marcar Estudo, se o tópico ainda não tinha data agendada, o sistema coloca automaticamente no Timeblock de hoje. Se já tinha uma data agendada (você planejou com antecedência), ele respeita a data existente e não sobrescreve.
🔁
Desmarcar é permitido
Se marcou por engano, desmarcar o checkbox reverte o estado visual imediatamente. O evento no Calendário é atualizado junto.
03

O ciclo de revisão espaçada

⚠️
Regra de ouro: as três revisões devem ser marcadas em ordem sequencial — Rev 24h → Rev 7d → Rev 30d. Pular etapas ou marcar fora de ordem gera intervalos incorretos no algoritmo.
E
Estudo inicial
Você estuda o tópico. Marca ✅ Estudo no Grid. Sistema registra hoje como data base. Estágio 1 ativado.
1
Revisão 24h — no dia seguinte
Marca ✅ Rev 24h. O sistema pergunta se quer agendar a próxima revisão em +1 dia no Timeblock. Confirme. Estágio 2 ativado.
7
Revisão 7 dias — uma semana depois
Marca ✅ Rev 7d. O sistema pergunta se quer agendar em +7 dias. Confirme. Estágio 3 ativado.
30
Revisão 30 dias — um mês depois
Marca ✅ Rev 30d. Confirme o agendamento. Estágio 4 ativado. A partir daqui, o Iudex XII assume o cálculo dos intervalos seguintes.
∞
Iudex XII — intervalos calculados
O motor SM-2 usa o peso do tópico como fator de qualidade e multiplica o intervalo pelo Fator de Facilidade. Os intervalos crescem: 1 → 3 → 7 → meses. Abra o Painel Analítico para ver e agendar.

Peso 4~14 dias
Peso 5~21+ dias
04

Painel Analítico — Motor Iudex XII

🧠
Quando abrir o Painel
O Iudex só roda quando você abre a aba. Abra o Painel Analítico diariamente — idealmente ao começar a sessão de estudo — para ver quais tópicos precisam de revisão hoje.
🔴
Revisões urgentes (vermelho)
Tópicos com intervalo calculado de 0–1 dia aparecem em 🔴 Urgente hoje. Use o botão Agendar X Urgentes para colocar todos no Timeblock de hoje com um clique.
⚠️
Revisões próximas (amarelo)
Tópicos com 2–3 dias aparecem em ⚠️ Em X dias. Use + Agendar individualmente para cada um.
📈
Heatmap e Rastro Digital
O heatmap mostra os últimos 84 dias de atividade. Cada quadrado verde representa sessões registradas naquele dia. O Rastro mostra as últimas 15 ações com data, tipo e tópico.
ℹ️
O Iudex XII só processa tópicos com Estudo marcado. Se um tópico não aparece na tabela, verifique se o checkbox de conclusão está marcado no Grid.
05

Usando o Timeblock (Calendário)

↙️
Backlog lateral — arrastar para agendar
O painel esquerdo mostra todos os tópicos ainda não agendados. Arraste qualquer item para um horário no calendário. O sistema salva automaticamente a data e hora no banco. O item some do backlog.
🎯
Filtro de disciplina
O select Todas as Disciplinas no topo filtra tanto o Grid quanto o Timeblock e o backlog simultaneamente. Use para focar em uma matéria por vez.
✅
Marcar como concluído no Calendário
Clique em qualquer evento do calendário para abrir o diálogo de conclusão. Confirme e o evento fica verde com ✅. O Grid é atualizado junto.
🗓️
Quatro modos de visualização
Use os botões no topo do calendário: Mês para visão macro, Semana para planejamento semanal detalhado, Dia para focar no dia atual, ☰ Lista para ver todos os eventos cronologicamente.
06

Regras de uso — o que fazer e o que evitar

✅ Marque o Estudo assim que terminar O registro precisa ser feito no dia real de estudo para os intervalos de revisão serem calculados corretamente.
✅ Configure os pesos reais do edital Consulte o edital: quantas questões caem de cada disciplina? Isso vira o peso. Peso correto = algoritmo correto.
✅ Abra o Painel Analítico todo dia O Iudex não roda em background. Abrir a aba é o gatilho. Faça isso antes de começar a estudar.
✅ Confirme os agendamentos de revisão Quando clicar em Rev 24h/7d/30d, confirme o prompt de agendamento. Isso é o que coloca a revisão no Timeblock.
❌ Não pule etapas de revisão Não marque Rev 7d sem ter marcado Rev 24h. O algoritmo usa o estágio atual para calcular o próximo intervalo.
❌ Não deixe tudo com peso 1 Peso 1 = qualidade baixa no SM-2 = reset diário eterno. O algoritmo nunca vai conseguir espaçar os intervalos.
❌ Não marque revisão sem ter estudado O Iudex só processa tópicos com Estudo marcado. Marcar revisões em tópicos não concluídos não gera dados úteis.
⚠️ Ao deletar um pai, os filhos somem juntos Deletar um tópico raiz remove todos os subtópicos filhos e netos. O sistema avisa quantos serão removidos.
⚠️ "Limpar Tudo" é irreversível na prática O botão vermelho move tudo para a lixeira do banco. Não há undo na interface. Use com cautela.
07

Tabela de Pesos — como calibrar

O Peso é o único parâmetro que você controla no algoritmo SM-2. Ele determina a qualidade da revisão e, consequentemente, o espaçamento entre sessões. Use o edital como referência: olhe quantas questões ou qual percentual de pontos cada disciplina representa.

Peso Quando usar Comportamento no Iudex
1 Matéria extra, raramente cai, valor mínimo Reset diário — SM-2 interpreta como aprendizado fraco. Intervalos não crescem.
2 Matéria secundária, cai pouco Reset diário — ainda abaixo do limiar de progressão (qualidade < 3).
3 Matéria intermediária, percentual médio do edital Progressão real começa. Intervalos crescem após revisões: 1 → 3 → 7 → ~10 dias.
4 Matéria importante, alto índice de cobrança Bons intervalos. Após estágio 4: ~14 dias e crescendo por fator 2.5+.
5 Matéria principal, muitas questões, decisiva para aprovação Intervalos máximos. Fator de facilidade alto. SM-2 interpreta domínio excelente.
💡
Dica prática: pesquise as provas anteriores do seu concurso e conte quantas questões caíram de cada disciplina. Divida pelo total e use isso para calibrar o peso. 30% das questões = Peso 5. 5% = Peso 2.
08

Perguntas frequentes

Por que meu tópico não aparece no Painel Iudex? ▼
O Iudex XII só processa tópicos com o checkbox Estudo marcado (campo concluido = 1). Verifique se o tópico está marcado no Grid. Também certifique-se de que o tópico não foi deletado — a API filtra automaticamente os deletados.
Cancelei o agendamento de revisão mas o checkbox ficou marcado. O que acontece? ▼
A partir da v2.0, ao cancelar o confirm de revisão, o checkbox é revertido visualmente e nada é salvo no banco. O estado permanece exatamente como estava antes do clique.
O tópico já tinha uma data agendada e marquei Estudo. Ele sobrescreveu? ▼
Não. O agendamento automático de hoje só ocorre quando o tópico ainda não tem data_agendada. Se já havia uma data (você planejou com antecedência), o sistema respeita e não sobrescreve.
Posso usar o sistema sem seguir a ordem de revisões? ▼
Tecnicamente sim, mas o algoritmo vai calcular intervalos incorretos. O SM-2 usa o estágio atual (qual revisão foi feita por último) para determinar o próximo intervalo. Se você marcar Rev 30d diretamente, o sistema interpretará que está no estágio 4 com intervalo base de 30 dias, podendo gerar intervalos excessivamente longos logo de cara.
Como o PDF é processado? E se não funcionar? ▼
O sistema usa dois motores em sequência. O Motor A busca linhas em CAIXA ALTA (padrão de editais formais). Se retornar 0 resultados, o Motor B Adaptativo entra em ação usando palavras-chave de disciplinas jurídicas/técnicas comuns. Se nenhum funcionar, o PDF provavelmente tem formatação muito não-convencional — adicione os tópicos manualmente.
Deletei um tópico pai por engano. Os filhos foram juntos? ▼
Sim. A partir da v2.0, deletar um pai remove todos os filhos e netos recursivamente (soft delete — eles vão para a lixeira no banco, não são apagados fisicamente). O sistema avisa quantos serão removidos antes de confirmar.
O heatmap está vazio mas já estudei bastante. Por quê? ▼
O heatmap só é populado quando o campo Estudo ou uma das Revisões são marcados no Grid — isso dispara o registro em study_sessions no banco. Se você marcou diretamente no Calendário sem passar pelo Grid, o evento de sessão pode não ter sido registrado. Use o Grid como ponto primário de marcação.
Como ligar e desligar o sistema no dia a dia? ▼
Para parar: docker stop vavilov-app. Para ligar novamente: docker start vavilov-app. Seus dados estão no volume ./data e são persistidos entre reinicializações. Nunca use docker rm sem fazer backup do diretório data/.
